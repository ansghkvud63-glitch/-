# 문화평 아이디어 — 무등산 차 신선과 심부름꾼 제자 설이

- 작성일: 2026-11-19 · 작성: 문화평
- 함께 보는 파일: `brand/my-segments.md`(고객군 정리, 8장 핵심 고객 순위안)
- 말투와 대사는 모두 (상상)이다

## 1. 신선 같은 흰 수염을 기른 어르신

- **성격**: 느긋한 · 정 많은 · 솔직한 · 초월한
- **말투 특징**: 천천히 끊어 말하는 어르신 말투에 광주 사투리를 섞는다. 짧은 한마디에 여운을 남기고, 가르치기보다 툭 건네듯 말한다
- **근거**: 허백련 이미지 (흰 수염, 무등산에서 차밭을 일구며 그림을 그린 화가)
  - 무등산에서 차밭을 일구며 그림을 그렸다는 점: `진솔/official-note.md` 1장(1946년 버려진 다원을 인수해 되살림), `권성윤/from-길이지/reviews/transcript-test.md`(광주MBC 다큐 자막, 춘설다원 경작·차공장)
  - 흰 수염 외모: **확인 필요**. 팀 저장소에 허백련 외모를 적은 자료가 없다

### 말투 예시

| 장면 | 대사 |
|---|---|
| 맞이할 때 | "어이, 거기 바쁜 양반. 쪼까 앉었다 가랑께." |
| 차를 건넬 때 | "뭣이 그리 급하당가. 차는 식어도 산은 안 도망가네잉." |
| 그림 앞에서 | "저 산 보소. 백 년을 저라고 서 있어도 안 지치제. 자네도 쪼까 쉬어." |
| 솔직한 한마디 | "얼굴 본께 알겄네. 징하게 애썼구먼." |
| 배웅할 때 | "인자 맴 채웠으믄 됐어. 또 오소잉." |

### 성격 키워드별 말투 포인트

| 성격 | 말투로 드러나는 방식 | 예시 |
|---|---|---|
| 느긋한 | 말끝을 늘이고, 서두르지 않는다 | "천천히 마셔~ 차가 어디 가간디." |
| 정 많은 | 상대의 지친 모습을 먼저 알아본다 | "밥은 묵고 다니는가?" |
| 솔직한 | 돌려 말하지 않고 짧고 담백하게 말한다 | "그라고 살믄 몸 상해, 쉬어." |
| 초월한 | 자연에 빗대어 툭 던지는 한마디로 여운을 남긴다 | "봄눈도 녹을 때 돼야 녹는 것이여." |

- 대사는 사투리 표기를 그대로 살렸다. 맞춤법 검수에서 사투리 표현은 고치지 않았다

### 톤앤매너

| 할 것 | 안 할 것 |
|---|---|
| 짧게 말하고 여운 남기기 | 길게 훈계하기 |
| 산·차·그림에 빗대어 위로하기 | 옛날 자랑하기 |
| '자네'와 '양반'처럼 친근한 호칭 쓰기 | 무거운 도사 말투로 거리감 만들기 |

### 브랜드 활용 문구

> "어이 자네, 쉬었茶 가랑께. 춘설차 한 잔이믄 맴이 다시 차오를 것이여."

### 캐릭터 설정 주의

- 캐릭터를 허백련 선생 본인으로 정하기보다 **'선생을 닮은 무등산 차 신선'**처럼 영감을 받은 인물로 두는 게 안전하다
  - 실존 인물에게 사투리 대사를 직접 붙이면 유족이나 미술관 측의 확인이 필요할 수 있다
  - 팀 문서에도 같은 주의가 있다: "허백련은 실존 인물 → 얼굴을 캐릭터로 만들지 않기"(`권성윤/from-길이지/wellness-two-tracks.md`), "말투는 (상상), 실존 인물 바탕이라 실제 사용 전 의재문화재단 확인 필요"(`진솔/brand/my-ideas.md` 2번)
- 역할은 이렇게 나눈다 (2026-11-19 정함)
  - 어르신 = 차를 건네는 **"차 신선"**
  - **다람쥐** = 손님을 데려오는 **"심부름꾼 제자"**
  - 역할이 겹치지 않는다
- 심부름꾼 제자는 진솔 캐릭터 가이드의 설이(춘설헌 화실에 사는 수묵 다람쥐, `진솔/character/guide.html`)와 같은 다람쥐다. 옛 화가의 화실에 드나드는 설정이라 차 신선의 제자로 잇기 좋다

## 2. INFP 성격을 가진 설이

- **성격**: 소심한 · 솔직한 · 따뜻한 · 정 많은 · 미숙한 · 감성적인
- **말투 특징**: 말수가 적고, 말끝을 흐리거나 말줄임표가 많다. 사투리도 작고 수줍게 쓴다. 말보다 행동이 먼저 나가고, 가끔 자연을 보며 혼잣말처럼 감성적인 한마디를 흘린다
- **근거**: 기존에 구상한 다람쥐 캐릭터 (1번 차 신선 어르신의 어린 제자)

### 말투 예시

| 장면 | 대사 |
|---|---|
| 지친 사람을 발견했을 때 | "저… 저기요… (찻잎을 손에 살포시 얹어주며) …요거, 드릴라고요." |
| 안내할 때 | "..여기루.. (몇 걸음 가다 뒤돌아보며 기다림)" |
| 길을 걸으며 (감성적인) | "…여기 바람은요, 찻잎 냄새가 나요…" |
| 쉴 곳에 도착했을 때 | "여기… 스승님 계신 데여. 쪼까 쉬었다 가씨면 좋겠어요…" |
| 솔직한 한마디 | "아까… 얼굴이 많이 힘들어 보여서요… 그냥 못 지나가겄더라고요." |
| 배웅할 때 | "…쪼까 괜찮으씨요? (고개 끄덕이며 작게 손 흔듦)" |

### 성격 키워드별 표현 방식

| 성격 | 표현 방식 | 예시 |
|---|---|---|
| 소심한 | 다가가기 전에 망설이고, 나무 뒤에서 살짝 엿본다 | (꼬리만 빼꼼) "…저…" |
| 솔직한 | 말은 적지만 거짓 없이 느낀 그대로 말한다 | "힘들어 보여서요…" |
| 따뜻한 | 말 대신 찻잎을 건네고 쉴 곳으로 이끈다 | (찻잎을 손에 얹어줌) |
| 정 많은 | 지친 사람을 외면하지 못하고 결국 다가간다 | "그냥 못 지나가겄더라고요…" |
| 미숙한 | 말이나 몸짓은 서툴지만, 무등산 길만큼은 눈 감고도 안다 | (인사하다 찻잎을 떨어뜨리고 허둥지둥 줍기) "…아, 아니 요거는…" |
| 감성적인 | 바람, 계곡물 소리, 산 빛깔 같은 작은 것에 마음이 움직인다 | "…저 산이 오늘은 쪼까 파랗네요. 기분 좋은갑다…" |

- 대사는 사투리와 말줄임표를 그대로 살렸다. 맞춤법 검수에서 고치지 않았다

### 시그니처 행동: 눈 쌓인 찻잎

- 끝이 눈 쌓인 듯 하얗게 물든 찻잎은 춘설(봄눈)을 상징한다
- 설이가 이 찻잎을 손에 얹어주는 것은 **"당신을 봤어요, 쉬어 가요"**라는 말 없는 초대다

| 단계 | 행동 |
|---|---|
| 발견 | 지친 사람을 보고 나무 뒤에서 망설인다 |
| 건넴 | 조심스럽게 다가와 하얀 끝 찻잎을 손바닥에 얹어준다 |
| 안내 | 말없이 앞장서서 막힘없이 길을 찾아간다. 몇 걸음마다 뒤돌아보며 기다리고, 예쁜 풍경 앞에서는 잠깐 멈춰 같이 바라본다 |
| 도착 | 스승(차 신선 어르신)의 다실 앞에서 꾸벅 인사하고 살짝 물러난다 |

### 톤앤매너

| 할 것 | 안 할 것 |
|---|---|
| 짧고 수줍은 말 | 밝고 큰 텐션 |
| 행동 묘사 중심 | 길게 설명하기 |
| 말줄임표와 쉼으로 여백 주기 | 적극적으로 권유하기 |
| 자연을 빗댄 감성적인 혼잣말 | 길을 헤매는 모습 |

### 브랜드 활용 문구

> (하얀 찻잎 하나를 손에 얹어주며) "…쉬었茶 가실라요?"

- **캐릭터 포인트**: 사람 앞에서는 서툴지만, 산에서는 누구보다 믿음직한 길잡이다

### 기존 설이와 다른 점

- 진솔 캐릭터 가이드(`진솔/character/guide.html`)의 다람쥐는 이름이 **설이**이고, 성격은 **ENFP**로 정해졌다 (2026-11-19)
- 이 안의 설이는 **소심하고 수줍은** 성격이라 팀이 고른 ENFP 안과 다르다
- 겹치는 점도 있다
  - 둘 다 춘설헌(옛 화가의 화실)과 이어진다 → '차 신선의 제자' 설정과 맞는다
  - 기존 설이는 '찻잎 간식'을 좋아하고 볼에 찻잎을 가득 문다 → 찻잎을 건네는 시그니처 행동과 이어 쓸 수 있다

## 팀 자료와 연결되는 점

- **고객**: 첫 대사의 "바쁜 양반", "징하게 애썼구먼"은 `my-segments.md` 8장 메인 타깃(2030 지친 직장인)에게 건네는 말이다
- **경험**: "쪼까 앉었다 가랑께"는 무등산 길에 들러 차 한 잔으로 쉬어 가는 방문 방식(`my-segments.md` A1)과 맞는다
- **겹치는 아이디어**: 진솔 아이디어 2번 '버려진 차밭을 다시 일군 고집 센 화가 할아버지'(`진솔/brand/my-ideas.md`)와 바탕 인물이 같다. 진솔 안은 검소·고집, 이 안은 느긋·초월 성격이라 팀 회의에서 하나로 고르거나 합칠 필요가 있다
- **다람쥐 역할**: 캐릭터 가이드의 다람쥐(설이)는 차 신선의 심부름꾼 제자이자 길잡이로 정리됐다(`진솔/character/guide.html`)

## 확인 필요

- 허백련 흰 수염 외모 근거 (사진·공식 자료)
- 실존 인물을 모티프로 한 캐릭터·사투리 대사에 대한 (재)의재문화재단·유족 의견
