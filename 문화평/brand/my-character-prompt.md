# 캐릭터 디자인 — 차 신선 · 설이 (11/19)

- 바탕 파일: `진솔/brand/team-world-bible.md` (팀 세계관), `진솔/brand/character-guide.md` (설이 가이드), `brand/personadetail.md`, `brand/brand-skill.md`
- 표기: **(팀)** = 팀 파일에 정해진 것 · **(제안)** = 팀 파일에 없어서 이 문서에서 제안하는 것 · **(상상)** = 이야기 속 설정
- 차 신선 참고 이미지: 사용자가 준 웹툰풍 그림(긴 흰 머리·흰 수염, 찻잔을 든 손, 넓은 소매 옷, 눈 감은 얼굴). **분위기와 자세만 참고하고 얼굴·머리 모양·옷 디자인은 따라 그리지 않는다.** 이미 있는 작품의 캐릭터이기 때문이다

> **지킬 것**
> - 차 신선은 허백련 선생 본인이 아니다. "허백련 선생을 닮은 무등산 차 신선"까지만 쓴다 (`brand/brand-skill.md` 5장)
> - 허백련의 흰 수염은 팀 저장소에 근거가 없다. 캐릭터 외모일 뿐 실제 모습이라고 하지 않는다 (`brand/personadetail.md`)
> - 실제 사람(허백련 선생 사진 포함)과 이미 있는 캐릭터(참고 이미지 포함)를 닮게 그리지 않는다

## 1. 차 신선

### 1-1. 기본

| 항목 | 내용 |
|---|---|
| 종류 | 사람. 차를 대접하다 등선한 뒤 무등산으로 다시 내려온 신선 (팀, 상상) |
| 그림체 | 설이와 같은 세트로 보이게: 3D 피규어 · 무광 클레이 질감, 옷 무늬와 먹선만 수묵 붓 터치, 부드러운 스튜디오 조명 (제안 — 팀 그림체는 설이 가이드에만 있다) |
| 대표 색 3개 | ① 봄눈 흰색 — 머리·수염 ② 한지 미색 `#F3EEE3` — 옷 ③ 먹색 `#222222` — 옷깃·고름·붓 (팀 색 목록 `team-world-bible.md` 7-4에서 고름, 제안) |
| 작은 포인트 | 새순 연두 `#7CB342`(찻잔 속 차), 낙관 붉은색 `#B8322A`(허리 끈 끝 작은 도장) — 설이와 같은 색 |
| 이름 | **차 신선**, 부를 때 **스승님** (팀). 고유 이름은 팀에서 아직 정하지 않았다 |
| 성격 | 느긋한 · 정 많은 · 솔직한 · 초월한 (팀, `brand/personadetail.md` 1장) |

### 1-2. 외형

| 항목 | 내용 |
|---|---|
| 몸 비율 | 약 3등신. 설이(약 2등신)보다 크고, 옆에 서면 설이가 무릎 높이쯤 온다. 어깨가 둥글고 옷이 아래로 넓게 퍼져 앉은 모습이 안정적이다 (제안) |
| 옷 | 한지 미색 도포(두루마기 모양 겉옷). 소매가 넓고 길게 늘어진다. 깃·고름·소매 끝에 먹색 선을 붓으로 그은 듯 넣고, 허리에 먹색 세조대(가는 끈)를 맨다. 발에는 짚신 (제안). '남도식·광주식 한복'만의 특징은 팀 자료에 없어서 기본 선비 도포 모양으로 두었다 (확인 필요) |
| 머리 | 봄눈처럼 흰 머리를 정수리에 작게 틀어 올리고(상투) 먹색 끈으로 묶음. 수염은 가슴까지 내려오는 흰 수염, 끝이 붓끝처럼 모인다 (제안) |
| 소품 | ① **수묵 붓 한 자루** — 허리끈에 꽂음. 허백련이 그린 산수화·화조도 같은 수묵화용 긴 털 붓 모양 (작품 갈래는 `post-uijae-forest-museum.md`, `video-uijae-architecture-shorts.md`. 붓 종류는 자료에 없어 모양만 표현, 확인 필요) ② **연두 차가 담긴 작은 찻잔** — 한 손으로 받쳐 듦 (팀: 차는 신선만 따른다) ③ **먹색 머리끈** ④ 허리끈 끝 **작은 붉은 낙관** — 설이 가슴 낙관과 짝 |
| 표정 | 기본: 눈을 반쯤 감고 입꼬리가 살짝 올라간 여유로운 미소. 인자함: 눈가 주름이 웃음선으로 보이게. 크게 웃거나 화내지 않는다 (팀 성격 '느긋한·초월한'에 맞춤, 제안) |
| 어디서 왔나 | 흰 수염 어르신이 무등산을 넘나드는 이들에게 차를 대접하다 어느 봄날 등선했다. 산 아래 시름이 깊다는 소리를 찻물 끓는 소리로 듣고 다시 무등산에 내려와, 먼저 버려진 차밭부터 돌보았다. 지금은 다실을 떠나지 않고 차를 건넨다 (팀, 상상, `team-world-bible.md` 2-1·3-1) |

캐릭터: '차 신선', 무등산에 사는 인자한 노인 신선. 약 3등신, 둥근 어깨, 아래로 넓게 퍼지는 옷.
말랑한 3D 피규어 질감, 무광. 옷의 선과 무늬만 수묵 붓 터치.

### 2-2. 외형

| 항목 | 내용 |
|---|---|
| 몸 비율 | 약 2등신. 머리가 키의 절반쯤, 아래로 퍼진 빵빵한 볼, 둥근 배, 짧은 팔다리 (팀) |
| 옷 | 기본은 옷 없음, 먹 줄무늬가 몸을 꾸민다 (팀). 한복을 입힐 때만: 스승 도포와 같은 한지 미색 짧은 배자(조끼)에 먹색 깃 — 꼬리와 가슴 낙관을 가리지 않게 (제안) |
| 소품 | ① **붓 꼬리** — 흰 털에서 끝으로 갈수록 먹색, 뿌리에 갈색 나무 붓대 띠. 화실 먹물 그릇에 빠뜨려 생겼다 (팀) ② **가슴 낙관** — 작은 붉은 사각 도장 (팀) ③ **하얀 끝 찻잎** — 입에 2~3장 물거나 앞발로 1장 듦. 아래 2/3 연두, 끝 1/3 흰색. 실제 춘설차 잎의 특징이 아니다 (팀, 상상) |
| 머리·귀 | 이마에 먹 줄무늬 3줄, 눈가 먹 아이라인. 귀는 길고 뾰족하게, 끝에 작은 털 뭉치 — 고양이·호랑이로 읽히지 않게 (팀, `character-guide.md` 8장) |
| 표정 | 기본: 반짝이는 큰 눈에 찻잎을 문 얼굴. 활짝 웃음: 이를 드러내고 찻잎을 꽉 묾. 지친 손님 앞: 웃음을 줄이고 찻잎을 조심스레 내미는 얼굴 (팀 표정 + 세계관 3-2 말투 규칙 3) |
| 어디서 왔나 | 옛 화가의 화실(춘설헌)에 드나들던 다람쥐. 먹물 그릇에 꼬리를 빠뜨려 꼬리 끝이 붓처럼 됐다. 신선이 다시 가꾸는 차밭에 찻잎 간식을 따라왔다가 봄눈 맞은 첫 잎을 먹고 말하는 영물이 됐다 (팀, 상상). 춘설헌은 허백련이 1946~1977년 살며 작업한 곳이다 (사실, `진솔/official-note.md` 1장) |

## 3. 둘을 함께 둘 때

- 크기: 신선 약 3등신, 설이는 신선 무릎 높이 (제안)
- 공통 요소: 한지 미색 · 먹색 붓선 · 작은 붉은 낙관 — 둘이 한 세트로 보이게 한다
- 역할 구분: 찻잔은 신선만 든다. 설이는 찻잎만 든다 (팀 규칙 2 "차는 신선만 따른다")

## 4. 팀에서 정할 것

- [ ] 차 신선 그림체를 설이와 같은 3D 피규어로 할지, 참고 이미지 같은 2D 일러스트로 할지
- [ ] 차 신선 고유 이름 (지금은 "차 신선" / "스승님")
- [ ] '남도식·광주식 한복'의 특징 — 팀 자료에 없어서 기본 도포로 두었다
- [ ] 허백련 선생을 떠올리게 하는 캐릭터에 대한 (재)의재문화재단·유족 의견 (`team-world-bible.md` 9장)
